Cue — macOS setup

Requires macOS 14 or later. This image is built for the architecture in its filename (arm64 = Apple Silicon).

1. Drag Cue.app onto Applications, then open it from Applications.
2. Keep an internet connection for the first launch. Cue automatically downloads its Roman Hinglish + English speech model (approximately 824 MB), then prepares it for this Mac. This can take several minutes. The model is stored in your user Application Support folder and reused on subsequent launches. Call audio is processed locally.
3. Open Cue Settings. Under On-device transcription you can see model status and use Download / load speech model to retry after a download failure.
4. In Cue Settings, open Connect Chrome and choose Open Cue Chrome. Cue opens a separate Chrome profile, loads its extension, and links its ID automatically. Sign in to Google in that Chrome window and use it for your calls. No Developer mode, folder selection, or extension ID copying is needed. Use Open Cue Chrome each time you reopen this profile: Chrome does not restore automatically loaded extensions by itself. Your sign-in and browser data are retained.
5. Your regular Chrome profile stays separate. To use that profile instead, expand Manual setup in your existing Chrome profile. The separate Cue Extension folder on this disk is also included for inspection or manual copying. Do not load it directly from the mounted disk: Chrome needs a permanent folder after the disk is ejected.
6. Existing users: keep the current extension ID and unpacked folder to preserve browser history. Do not install a duplicate extension. Update/reload only outside a call.
7. Eject this disk after installation. Your calls and downloaded model are kept separately from the application.

Check the release notes for this image’s signing and notarization status. Local source builds use ad-hoc signing by default; release builds can use Developer ID signing. Signing alone is not Apple notarization, and macOS may block a downloaded image that is not notarized.

AI summaries and coaching download the selected provider’s pinned tools on first use (internet required). Settings shows setup progress and lets you retry. Tools are cached in your Application Support folder, separately from the app. Only the selected provider is downloaded. These features use the separately configured provider; the speech model download does not include cloud AI credentials or subscriptions.
